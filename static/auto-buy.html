최대 주문 원금—수수료 별도 · 미수 없는 주문가능 금액으로 확인

선택한 날 15:20까지 대기합니다. 정규장 연속매매 중에만 새 주문합니다. 접수된 지정가 주문은 별도로 잔량 취소해야 합니다.

둘 중 하나 이상 입력하세요. 기존 보유가 없는 종목만 연결하며, 실제 평단을 기준으로 체결 수량 전부를 시장가 매도합니다. 보유기간 청산은 없습니다.

일부만 체결되고 잔량이 남아 있으면 자동매도 감시는 아직 시작하지 않습니다. 전량 체결 또는 잔량 종료와 잔고 일치가 확인된 뒤 연결합니다.

이 단계에서는 주문하지 않습니다. 확인 화면에서 직접 켜야 매수 대기가 시작됩니다.

02 · 시작 방법

확인하고, 직접 켜기

  1. 종목·매수가·수량 입력
  2. 키움 종목명과 최대 금액 확인
  3. 실전 / 모의 계좌 확인 후 켜기
  4. 주문 접수와 체결을 각각 확인

알아두세요

  • 26만 원 지정가 매수는 26만 원 이하에 사겠다는 뜻입니다. 26만 원 돌파 매수가 아닙니다.
  • 같은 종목의 자동매도가 켜져 있거나 미확정 주문이 있으면 매수를 막습니다.
  • 잔고 변경·연결 중단·서버 재시작 시 새 주문과 자동매도 연결을 중지합니다.
  • 주문 접수 후에는 PC를 꺼도 증권사에 남은 주문이 체결될 수 있습니다.
  • 화면의 대기 중지와 미체결 잔량 취소는 다릅니다.

매수 후 자동매도

잔량 취소는 키움으로 실제 취소 주문을 보냅니다. 취소 접수만으로 완료로 표시하지 않습니다. 이 버튼으로 취소하면 이후 자동매도 연결도 해제되므로 체결된 수량은 직접 확인하세요.
