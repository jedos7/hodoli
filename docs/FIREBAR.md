# 🔥 기준봉 종가 (변성환 규칙)

화면: `http://127.0.0.1:8000/firebar.html` (관제탑의 **🔥 기준봉 종가** 버튼). 코드: `app/firebar.py` (🌙 종가배팅 `app/closebet.py` 의 뼈대를 물려받음) · 서비스 `app/overnight_service.py`.

오늘 대금이 터진 기준봉 가운데 **윗꼬리 없이** 마감하는 종목을 종가에 사서 다음 날 시초가에 팝니다.

## 하루 흐름 (평일, 서버가 떠 있을 때만)

| 시각 | 하는 일 |
|---|---|
| 15:10~15:14 | 거래대금 상위에서 조건 판정 → 통과 종목을 **대금 큰 순**으로. 화면 표와 텔레그램 |
| 15:19:40 | **주문 직전에 윗꼬리·등락을 다시 확인**하고, 통과한 종목을 지금 값 +2틱 지정가로 매수 (현금 1배) |
| 15:31 | 체결 조회 → 보유 등록 |
| 다음 거래일 08:40 (설정) | 시장가 매도 → 09:00 시초가 체결. 손절 없이 무조건 |
| 09:03 | 체결 대조. 안 팔렸으면 장중 시장가로 한 번 더 |

🌙 종가배팅(15:19:50)보다 **10초 먼저** 주문합니다. 문서의 우선순위(🌅 → 🗻 → 🔥 → 🌙)를 시각으로 지킨 것입니다.

## 조건 (규칙 문서 그대로)

- 오늘 등락 **+15% 이상 +29% 미만** — 상한가에 잠기면 종가에 못 사므로 제외
- 거래대금 **문턱 이상**(기본 300억) · 앞 **20일 평균 대금의 5배 이상**
- 전날 종가 **1,000원 이상** · ETF·ETN·스팩·레버리지·리츠 이름 제외 · 실전 전송 전 키움 종목 상태(거래정지·투자유의) 확인
- **윗꼬리 = (고가 − 지금 값) ÷ 전날 종가 < 2%p** — 고가 근처에서 끝나는 종목만

문서가 "15:10 · 15:15 값으로 판정"이라고 해서, 15:10에 1차로 고르고 **15:19:40 주문 직전에 등락 범위와 윗꼬리를 다시 확인**합니다. 15:10 이후 윗꼬리가 생기면 그 종목만 건너뜁니다.

등락·현재가·거래대금은 거래대금 순위 자료에 이미 있어 **일봉을 받기 전에** 판정합니다. +15~29% 밖인 종목은 일봉을 조회하지 않습니다
(2026-10-19 실제 자료: 83종목 중 81종목이 여기서 끝나 후보 선정이 57.8초 → 2.0초). 자세한 건 [API_RATE.md](API_RATE.md).

## 수량과 주문가

- 매수가 = **지금 값 + 2틱**, 상한가(전날 종가 × 1.3, 호가단위 내림)는 넘지 않습니다.
- 수량은 한 종목 금액 → 총 투입 상한 잔여 → 호가 총잔량 → 키움 주문가능 수량 순으로 깎입니다.
- 총 투입 상한 **999만 원 이하**, 종목 수 **5 이하**를 코드에서 막습니다. 현금 1배입니다.
- 같은 묶음 안에서 아직 체결 확인 전인 주문 금액도 총액에 포함합니다.

## 안전장치

🌙 종가배팅과 같습니다. 흉내(dry)가 기본이고 실전(live)은 실전 계좌 + 화면 확인란이 있어야 켜집니다. 전송 전 저널, 전송 1회, 응답 불명은 재전송 차단, 시간창 밖·연결 끊김·비상 정지면 **새 매수** 금지(매도는 막지 않음), 다른 엔진(🌙 🗻 🌅 내 조건)에 걸린 종목과 이미 보유 중인 종목은 건드리지 않습니다. 서버가 아침에 꺼져 있으면 그날 안 팔립니다.

## 성적 (제작자 자료, 우리 계좌 성과 아님)

213번 PF 4.34. 네 매매를 같이 돌리면 129번 PF 3.20. **최근 30번은 PF 2.44** 로 누적보다 낮아 제작자도 지켜보는 중이라고 적혀 있습니다. 제작자도 "검증은 일봉으로 했고 실전은 15:15 값으로 고르므로 문턱 근처에서는 결과가 갈릴 수 있다"고 적었습니다.

## API

`GET /api/firebar` · `POST /api/firebar/settings` · `/stop` · `/scan`(미리보기) · `/reconcile`. 로컬 주소·같은 출처·화면 토큰(`X-Firebar-Token`)만 받습니다. 저장 파일 `data/firebar_<계좌해시>.json`.

테스트: `tests/test_firebar.py` 8개 (윗꼬리·상한가 계산, 통과/거절 조건, 15:19:40 창, 지금 값 +2틱 매수, 상한가 상한, 주문 직전 재확인, 흉내 전 과정).
