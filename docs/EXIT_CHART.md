# 내 조건 자동매도 차트

`/custom-exit.html`에서 보유 종목 또는 저장된 계획의 **차트 보기**를 선택한다.

- 1분 / 5분 / 15분 / 일봉 캔들과 거래량, 평단·이익보전·익절·손절 가격선.
- 입력 중인 값과 저장된 감시 조건을 구분한다. 미리보기 선은 점선이며 실제 주문 조건을 변경하지 않는다.
- 크게 보기, 봉별 OHLC·거래량 조회, 확대·축소, 드래그/방향키로 과거 이동.
- 화면을 보는 동안 20초마다 차트 조회. 서버는 같은 종목·주기에 15초 캐시를 적용한다. 기존 키움 시세 클라이언트의 호출 제한을 공유하며 한 번에 차트 한 페이지까지만 읽는다.
- 최근 봉 종가와 수신 시각·마지막 봉 시각을 표시한다. 조회 실패 시 이전 자료임을 표시하며 자료가 없는 캔들을 생성하지 않는다.
- 읽기 전용 `/api/price-chart/{code}`는 KRX `ka10080` / `ka10081` 시세만 조회한다. 계좌·주문 API나 감시 시작/중지 API를 호출하지 않는다.
- 차트가 매도 판단을 대신하지 않는다. 주문 엔진과 호라이즌 전략 코드는 변경하지 않았다.

검증: 가짜 시세 기반 Python API/파싱/캐시 테스트, JS 가격선·차트 전환·응답 순서·조회 실패 테스트, 브라우저 주기 전환·확대·이동·크게 보기 확인.
