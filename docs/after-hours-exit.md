# 내 조건 자동매도: 시간외 설정

`custom-exit.html` → 종목·조건·수량 설정 → **시간외 매도**에서 시장 선택 → 필요하면 **미체결 재주문** 선택 → 조건 걸기 → 최종 확인 후 사용자가 감시를 켭니다.

기존 조건은 정규장 전용입니다. 이 기능을 추가해도 자동으로 켜지지 않습니다. 호라이즌의 익절·손절·보유 기간과 자동매수 방식은 유지됩니다.

## 거래시장과 가격

- KRX: 애프터마켓 16:00~20:00. 옛 시간외 단일가 주문(62)을 사용하지 않습니다.
- NXT: 프리마켓 08:00~08:50, 애프터마켓 15:40~20:00.
- 둘 다: 최신 체결가를 받은 시장을 사용하며 둘 다 최신이면 NXT 우선입니다. 두 시장에 중복 주문하거나 미체결 주문을 다른 시장으로 옮기지 않습니다.
- 정규장에는 기존 KRX 주문 방식을 사용합니다. 시간외 설정은 지원되는 현금 주식의 실계좌에만 제공됩니다.
- 시간외 시장가 조건은 보이는 매수호가 최대 10단계 중 가장 낮은 가격의 지정가로 전환합니다. 직접 입력한 지정가는 유지합니다.
- 호가가 없으면 기본 대기합니다. **하한가 지정가 허용**을 직접 선택한 시장가 조건만, 완전한 최신 호가 응답에서 매수잔량이 없는 경우 당일 하한가를 사용합니다. 응답 누락·시세 지연·조회 실패는 하한가 사용 사유가 아닙니다.
- 기한을 선택한 시간외 조건은 종료일 20:00까지 새 주문을 감시합니다. 이미 접수된 주문의 유효기간·잔량 취소는 증권사 주문내역에서 따로 확인해야 합니다.

## 미체결 재주문

손절·이익보전에만 선택할 수 있습니다. 익절에는 적용하지 않습니다.

1. 12초 간격으로 증권사의 원주문 체결·잔량을 조회합니다.
2. 현재 매수 1호가가 기존 지정가 아래이면 원주문 잔량 취소를 한 번 요청합니다.
3. 취소 접수만으로 재주문하지 않습니다. 원주문 잔량 0, 취소 확인수량, 최종 체결수량, 실제 보유·주문가능 잔고가 모두 일치해야 합니다.
4. 취소 중 체결된 수량을 제외하고 남은 수량만 현재 매수 1호가보다 한 호가 아래로 재주문합니다. 기존 지정가보다 올리거나 하한가보다 낮추지 않습니다.
5. 종목당 하루 최대 5회입니다. 5회 이후 마지막 지정가 주문 잔량은 유지되며, 주문내역에서 확인합니다.

연결 중단·감시 공백·재시작·취소 거부·응답 불명·잔고 불일치 시 재주문을 중지합니다. 취소·잔고·시세 확인이 60초 이상 지연되면 중지합니다. **재주문 중지 / 모두 끄기**는 이후 자동 처리를 멈추며 이미 접수된 주문을 취소하지 않습니다.

## 검증 범위

- 증권사 응답과 시계를 대체한 오프라인 테스트: 부분 체결, 취소 완료 확인, 중복 방지, 5회 제한, 시세 지연, 거래시장 불일치, 연결 중단, 재시작, 응답 불명 등.
- UI 테스트: 시장 선택, 익절 재주문 금지, 하한가 별도 선택, 확인창, 명시적 감시 시작.
- 실제 주문·취소·체결을 발생시킨 검증은 수행하지 않았습니다. 주문 접수와 실제 체결은 다릅니다.
