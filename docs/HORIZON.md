# 호라이즌 관제탑

기존 테마 레이더의 **호라이즌 관제탑** 버튼 또는 `/horizon.html`에서 연다.
기존 카드 화면과 매도조건 검증을 유지하는 별도 화면이다.

## 사용

- 시장 지수/수급/해외지표, 종목 표/카드, 선택 종목의 15분봉·지지선·조건별 이유를 표시한다.
- 전체 / D+2 / 관찰 / 제외·퇴출 필터, 종목·코드·테마 검색을 제공한다.
- 첫 방문에 읽기 전용 수집을 시작한다. 후보 분봉은 장중 수집 완료 후 60초 간격, 화면은 5초 간격이다. API 지연 시 실제 주기는 늘어날 수 있다.
- 첫 방문/새 날짜/15:40 이후에는 일봉 범위를 다시 수집한다. `다시 수집`도 동일하다. 수백 종목은 수분이 걸릴 수 있으며 진행 상황과 기존 자료를 함께 보여준다.
- 범위는 **기존 키움 일봉 캐시 + 현재 테마 종목 + 수집 당시 거래대금 100억 이상 종목**이다. 전 종목 전수 스캔이 아니다. 범위 밖 기준봉은 놓칠 수 있다.
- 키움에 연결되지 않았거나 조회가 실패하면 저장 자료만 표시한다. 현재 주문 가능한 후보로 간주하지 않는다.
- `판정 규칙`에서 최신 구현 정의, `참고 성적`에서 제작자 자료의 통계를 확인할 수 있다.

## 기준 및 우선순위

1. 기준봉: 상한가형(+29%, 종가/고가 ≥0.995, 100억) 또는 대금폭발형(+15%, 300억, 평소 5배).
2. 앞 10거래일에 기준봉이 있으면 제외. 기준봉 이전 과거자료를 충분히 확인하지 못하면 보류.
3. D+1 고가가 D0 종가 대비 +15% 이상이면 제외. 잠긴 상한가도 여기 포함된다.
4. D+1 오후 폭 ≤5%, |기울기| ≤0.1. 음의 기울기 초과만 D+1 종가>D0 종가이면 예외 허용. 양의 기울기 초과에는 예외 없음.
5. D+2 09:00~12:00 저가가 D+1 저가보다 한 번이라도 낮으면 퇴출. 회복과 등급에 관계없다. 같은 가격은 이탈 아님.
6. D+2 오전 폭 ≥4%. 11시는 미리보기, 12시에는 11~12시 봉까지 다시 검사한다.
7. S: 시총≥3,000억 & 상대강도<−3%p & 첫 시간 대금<평소 2배. A: (시총≥3,000억 또는 기준대금≥1,000억) & 상대강도<−3%p. B: 시총 또는 기준대금 조건. 높은 등급 하나만 표시한다.
8. 나머지 등급은 제외. 종목 상태상 거래정지·관리종목·불성실 공시·정리매매도 제외. 상태 미확인 시 조건 충족으로 올리지 않는다.
9. 12:00:00~12:00:59에 모든 조건과 최신성이 확인될 때만 `정오 조건 충족`. 늦은 관측은 정오 기준 사후 판정 기록이며 실제 매수 시각/신호의 영구 장부가 아니다.

## 원본 수식이 없어서 명시한 계산 정의

원 제작자의 소스·원시 자료는 제공되지 않았다. 문장상의 문턱을 구현했으며, 동일 결과를 보장하는 복제품이나 해당 성적을 재현한 백테스트가 아니다.

- 평소 대금: **D0 이전 20거래일 일대금 평균**. D0 자체를 포함하지 않는다.
- 폭: `(구간 최고가 / 최저가 − 1) × 100`.
- 기울기: 15분 종가를 구간 첫 종가 대비 수익률(%)로 바꾼 선형회귀 기울기, %p/봉.
- 상대강도: D+1 종목 종가 수익률 − 같은 날 코스닥 종가 수익률. 코스피 종목도 원문대로 코스닥 대비.
- HA 비율: 각 참고 구간 첫 봉의 시가·종가 평균으로 초기화한다. S/A/B와 진입 판단에는 사용하지 않는다.
- 평균 일중폭: D0 이전 최대 250봉 `(고가/저가−1)`의 평균. 실제 표본 수를 표시한다.
- 시총은 조회 시점의 값. D0 당시 시총을 복원하지 않는다.
- 키움 15분봉은 거래량을 제공하고 대금 필드가 없다. 첫 한 시간 대금은 `Σ 저가×거래량 ~ Σ 고가×거래량` 범위로 표시한다. **상한도 2배 미만일 때만 S**, 문턱에 걸치거나 자료가 없으면 A 이상으로 남긴다. 추정 중앙값을 실측 대금으로 사용하지 않는다.
- 공시 제외는 키움 종목 상태 문자열에 표시된 범위만 확인한다. DART 공시 원문 전수 검사나 뉴스 강도 자동 판정은 구현하지 않았다.

## 자료 보호 및 시간 처리

- D0/D+1/D+2는 코스닥 일봉의 실제 거래일로 센다. 주말·휴일을 달력상 평일로 추정하지 않는다.
- NXT·SOR 분봉을 요청하지 않으며 KRX 09:00~15:30만 사용한다.
- 요구 구간에 15분봉이 하나라도 빠지면 통과시키지 않는다. 거래가 없어 봉이 생기지 않는 종목도 확인 필요로 남는다.
- 아직 닫히지 않은 봉은 이탈 확인에만 쓴다. **봉 완성 여부는 서버 시계뿐 아니라 자료 수신 시각으로 제한**한다. 11:59의 자료를 12:00 완성 자료처럼 쓰지 않는다.
- 조회 180초 초과/미래 수신 시각은 현재 조건 충족으로 표시하지 않는다. 응답이 빠졌다고 0으로 대체하지 않는다.
- 분봉 연속 조회로 D+1 오후와 D+2 오전 전체를 확보한다. 재연결 후에도 과거 구간을 다시 확인한다.
- API: `ka10081` 일봉, `ka10080` 분봉, `ka20006` 코스닥, `ka10001` 시총/조회가, `ka10099` 종목 상태. 기존 호출 제한을 공유한다. [키움 공식 분봉 예제](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/examples/%EA%B5%AD%EB%82%B4%EC%A3%BC%EC%8B%9D/%EC%B0%A8%ED%8A%B8/get_domestic_stock_minute_chart.py)

## 매매/성과의 범위

- 이 화면은 **자동매수나 실제 매도를 하지 않는다**. 주문 API가 없다.
- 매도조건 검증은 기존 사용자 설정 **평단 +15% 전량 / −10% 전량 / 실제 매수일 후 2거래일 종가**를 유지한다.
- 제공자료의 2일/5일/7일 계획, 본전 지정가→종가, 레버리지·추적매도는 활성화하지 않는다.
- 과열·HA·재료·CVD 연구 방향은 참고로 구분한다. CVD를 OHLCV로 복원하지 않는다.
- 제작자 성적은 출처가 사용자 제공자료임을 명시한 별도 표다. 우리 계좌 성과·승률·예상수익으로 표시하지 않는다.
