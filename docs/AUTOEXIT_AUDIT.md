# 자동매도 재점검 — 2026-09-21

## 결론

코드의 결함을 재현하고 수정했지만 **실제 키움 모의투자 주문·체결 시험은 아직 하지 않았다. 실거래 작동을 보장하는 검증 결과가 아니다.** 점검을 위해 자동매도를 중단했으며, 점검 과정에서 실제 주문을 전송하거나 자동매도를 다시 켜지 않는다.

현재 규칙: 평단 대비 +15% 전량 익절, −10% 전량 손절, 최초 매수일 D0 이후 2거래일 뒤 마감 동시호가 매도 요청. 가격 조건은 비용 차감 전이다.

## 재현한 문제와 수정

1. **종가 매도 누락 가능성**: FID 214(장 시작 예상 잔여시간)를 마감까지 남은 시간으로 사용했다. 0이면 매도가 막히고 누락값은 예외가 발생했다. KRX 장 상태 2와 신호 시각으로 판정하도록 수정했다. 90초가 지난 신호로 새 주문을 만들지 않는다.
2. **NXT 메시지가 KRX 상태를 덮어씀**: 같은 `0s` 채널의 NXT 상태가 들어오면 KRX 익절·손절 판단이 중단될 수 있었다. 두 시장을 분리했다. 순서가 뒤바뀐 과거 KRX 신호도 최신 상태를 덮어쓰지 않는다.
3. **구독 전송을 성공으로 간주**: 성공 응답을 받기 전에 등록 완료로 처리했다. 이제 각 요청의 명시적 성공 응답을 기다린다. 거부·누락 응답은 연결 준비 완료로 보지 않으며 재접속 후 사용자가 다시 켜야 한다.
4. **무응답 연결 및 작업 종료 감지**: 메시지를 60초 동안 받지 못하면 연결을 해제한다. 계좌 감시나 주문 확인 작업이 끝나면 자동매도 준비 완료로 표시하지 않는다. 계좌 이벤트를 주식 체결 수신으로 집계하던 부분도 분리했다.
5. **동시 체결 조회와 시계 역행**: 수동 조회와 정기 조회가 겹치지 않게 했고, 주문 준비 중 PC 시간이 뒤로 바뀌면 전송을 중단한다.
6. **화면 신뢰성**: 자동매도 설정 화면에서 장 상태·시세 대기를 실제 감시와 구분한다. 조회 실패나 10초 초과 갱신 지연 시 종목 상태를 미확인으로 바꾼다. 조건 검증 화면의 중지 버튼이 실제 자동매도도 끈다는 점을 명시했다.
7. **시세 출처**: 통합·미확인 거래소 접미사가 있는 체결을 KRX로 분류하지 않는다. 종목코드 안의 영문 A도 훼손하지 않는다.

## 아직 남은 검증

- 실제 키움 모의투자 계좌에서 사용자가 직접 시작한 주문의 접수 → 부분/전량 체결 → 잔고 반영을 대조해야 한다. 현재 주문 상세 파서는 단일 주문 행을 확인하며, 복수 행/불명확한 응답은 완료로 추측하지 않는다.
- 실제 장중 KRX 0B 시세, 0s 장 개시·마감 알림 전달과 마감 동시호가 주문 수락을 관찰해야 한다. 공식 명세 대조와 가짜 패킷 테스트만으로 전달을 보장할 수 없다.
- D+2 당일 거래일 자료가 장중에 확보되는지 확인해야 한다. 자료나 최신 장 마감 신호가 없으면 기간 청산을 보류한다. 장중에 시작했을 때 장 개시 알림을 받지 못하면 가격 감시도 대기할 수 있다.
- 익절·손절은 연속매매 상태 3에서만 판단한다. 마감 동시호가에서는 D+2 조건을 판단하며, 최종 종가를 미리 알아서 익절·손절 주문을 보장하는 기능은 아니다.
- 주문 전 잔고 조회와 실제 전송 사이의 수동 주문, 서버에서 접수된 뒤의 중단, 통신 지연을 원자적으로 묶을 수 없다. 끄기는 이미 접수된 주문을 취소하지 않는다.
- 연결 장애 시 중단은 오주문을 줄이지만 손절을 대신 보장하지 않는다. 중지·대기·미확인 상태에서는 키움에서 직접 잔고와 주문을 확인해야 한다.
