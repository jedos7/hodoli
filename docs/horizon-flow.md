# 호라이즌 자리·수급

호라이즌 종목 선택 → 오른쪽 `자리 · 수급`. 참고 지표이며, 기존 등급 판정이나 주문 조건에 연결하지 않는다.

## 계산과 자료 범위

- 받은/털린 자리: 수신한 KRX 정규장 0B 체결을 실제 가격별로 합산. FID 15의 부호가 매수/매도 방향이며 현재가 등락 부호로 추정하지 않는다. POC는 수집된 매수+매도 수량이 가장 많은 가격. 최신 수집일 기준이며 시작·종료 시각 표시.
- CVD: `체결가 × 부호 있는 체결량`의 누적. 당일 중간 시작, 누락·재접속·재시작은 부분 수집 표시. 기준봉 자료가 없으면 미확인. 이전 일봉을 이용한 복원 없음. 기준봉 대비 비율은 기준봉부터 조회 거래일까지 날짜와 수신 연속성이 모두 확인되고 기준봉 CVD가 양수일 때만 표시.
- 매도벽: ka10004 매도 10호가를 15~20초 간격으로 관측. 같은 가격이 연속 관측된 횟수와 평균 잔량. 50초 초과 공백이나 날짜 변경 시 연속 횟수 초기화. 특정 주문이 계속 남아 있다는 뜻은 아니다. 정규장 30초 이내 호가만 새 관측으로 인정.
- 프로그램: ka90008 KRX 집계. 금액 백만원을 원으로 변환한 뒤 화면에서 억원으로 표시. 수량은 주. 조회 거래일 및 원자료 시각 표시. 프로그램 CVD와 체결 방향 CVD는 서로 다름.
- 창구: ka10038 순매수/순매도 정렬의 각 첫 페이지에서 상위 3개씩. 전체 창구 전수 통계가 아니며, 두 정렬에 중복된 창구는 합산하지 않는다. 최근 2거래일은 ka20006 지수의 거래량 있는 일자로 확인. 앞 거래일 순매수 → 최근 거래일 순매도 전환도 조회된 상위 창구 범위에서만 표시.

## 운영

- `/api/horizon-flow/{code}?since=YYYYMMDD`: 로컬·동일 출처 GET만 제공. 기존 시세 클라이언트 호출 제한 사용. 프로그램 60초, 창구 90초 캐시. 한 항목 실패 시 다른 항목은 표시하고 기존 자료의 시각을 보존.
- 종목 선택 시 해당 코드 시세 구독만 추가. 계좌 등록·주문·감시 켜기 호출 없음.
- 실시간 피드의 독립 observer에서 집계. 오류가 주문 observer/시세 갱신으로 전파되지 않는다. 주문용 기존 Trade.volume은 유지하고 signed_volume만 추가.
- `data/horizon_flow.json`에 15초마다 원자적으로 저장. 최근 45일·최대 3,000 종목일·종목일당 5,000 가격대 제한. 저장 실패 시 UI에 표시. 종료 시 저장 완료 대기.
- 실시간 자료가 없는 시각이나 미수집 종목에는 미확인을 표시한다. 과거 스크린샷의 수치를 실제 자료로 사용하지 않는다.

공식 필드 정의: [키움 REST API 명세](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/main/kiwoom/_data/kiwoom_api_spec.json), 0B·ka10004·ka90008·ka10038·ka20006.
